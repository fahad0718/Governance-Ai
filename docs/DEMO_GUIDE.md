# Demo Guide

## 1. Start
Run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 2. Use the built-in demo
In the sidebar, click **Load demo dataset**.

## 3. Review the metadata
The default example is a student performance classifier. Replace the fields with your own project details if needed.

## 4. Generate
Click **Generate Governance Package**.

## 5. Explain the dashboard
During the presentation, point out:
- Documentation completeness
- Governance gaps
- Number of checks
- Overall risk
- Recommended actions

## 6. Show the documents
Open the four tabs:
- Model Card
- Dataset Datasheet
- Governance Report
- Exports

## 7. Explain the innovation
The project does not only store model information. It compares the submitted documentation against governance requirements, highlights missing evidence, profiles the dataset, and turns the findings into exportable governance artifacts.

## 8. Important statement
Say: **“The platform is a governance documentation aid, not a compliance certification system. Human review remains necessary.”**
