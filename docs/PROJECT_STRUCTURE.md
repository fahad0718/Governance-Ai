## File responsibilities
- `app.py` — main Streamlit application.
- `requirements.txt` — Python dependencies.
- `sample_data.csv` — demonstration dataset.
- `README.md` — repository overview and setup instructions.
- `docs/PROJECT_REPORT.md` — academic project report.
- `docs/DEMO_GUIDE.md` — presentation/demo instructions.
- `docs/SYSTEM_ARCHITECTURE.md` — architecture and data flow.
- `docs/GOVERNANCE_METHODOLOGY.md` — governance checks and scoring logic.
- `docs/TEST_CASES.md` — test plan and acceptance criteria.
- `docs/TEST_RESULTS_TEMPLATE.md` — place to record actual execution results.
- `docs/USER_GUIDE.md` — end-user installation and usage instructions.
